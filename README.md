# Simulación de CUADRIGA en Unity y ROS 2

Este repositorio contiene los archivos desarrollados para la integración y validación del robot móvil CUADRIGA en un entorno de simulación basado en Unity, con comunicación mediante ROS 2.

El proyecto forma parte de un Trabajo Fin de Grado centrado en la incorporación del robot CUADRIGA al entorno virtual LAENTIEC, la adaptación de su controladora y la comparación de trayectorias entre el sistema real y el modelo simulado.

## Contenido del repositorio

El repositorio incluye:

- Archivos relacionados con la descripción URDF del robot.
- Scripts de control y comunicación entre Unity y ROS 2.
- Nodos auxiliares para la carga de trayectorias GPX.
- Scripts de procesamiento y comparación de trayectorias.
- Archivos empleados para la validación experimental.

## Requisitos

Para utilizar este proyecto se requiere disponer de:

- Unity.
- ROS 2.
- ROS-TCP-Connector.
- Python 3.
- Paquetes de ROS 2 necesarios para la ejecución de los nodos empleados.
- Dependencias específicas indicadas en la memoria del proyecto.

## Material multimedia

El material multimedia asociado al proyecto, como vídeos demostrativos, se encuentra disponible en la sección **Releases** de este repositorio.

Debido al tamaño de estos archivos, no se han incluido directamente dentro del código fuente del repositorio. En su lugar, se han añadido en una Release para facilitar su descarga sin afectar a la estructura principal del proyecto.

Para acceder al material multimedia:

1. Entrar en la pestaña **Releases** del repositorio.
2. Seleccionar la Release correspondiente al material multimedia.


Este material complementa la memoria del Trabajo Fin de Grado y permite visualizar el funcionamiento del sistema desarrollado, incluyendo las dos pruebas de simulación.
